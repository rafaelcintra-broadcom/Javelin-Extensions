Overview & Architecture

The GridTools.Javelin.HBaseActivities extension provides comprehensive Big Data connectivity between CA Test Data Manager (TDM) workflows and Apache HBase databases. It supports two distinct operational modes:

Mode 1: SSH Access (No REST API Required) Zero Cluster Changes
  • No REST daemon needed: Connects to an HBase client/edge machine via SSH and executes commands directly in hbase shell -n.
  • Automatic Output Parsing: Automatically parses columnar cell outputs and row counts into clean JSON and ADO.NET DataTables.
  • Kerberos / Keytab: Supports automated kinit execution prior to HBase command execution on secure clusters.
  • Port Forwarding Tunnel: HBaseSshTunnelActivity can create a dynamic local tunnel if REST is only available on localhost/internal VPC.
Mode 2: REST / Stargate API Direct HTTP
  • High Throughput: Direct HTTP/REST communication via Apache Knox Gateway or HBase REST daemon (port 8080).
  • Full CRUD: Native endpoints for Get, Put, Scan, Delete, and Table Admin.
  • Automatic Base64 Handling: Transparently handles HBase REST's mandatory Base64 encoding.
Included Activities Toolbox
  • HBase Get Row: Fetch single rows by RowKey or column
  • HBase Put Row: Insert/update rows from JSON or DataTable
  • HBase Scan: Range scan with filters and limit
  • HBase Delete: Delete rows, column families, or specific cells
  • HBase Table Admin: Create tables, check existence, drop
  • HBase Cluster Status: Ping and query cluster/version metrics

Enabling HBase REST Server

To connect from Javelin, start the HBase REST daemon on your Hadoop/HBase cluster:

# Start HBase REST daemon (default port 8080)
hbase rest start -p 8080 --infoport 8085

# Optional: verify with curl
curl -H "Accept: application/json" http://hbase-host:8080/version

Installation in Javelin Designer
  1. Copy GridTools.Javelin.HBaseActivities.dll and Newtonsoft.Json.dll to C:\ProgramData\CA\JavelinConfig\x64\Extensions\.
  2. Unblock files if copied from network: Unblock-File "C:\ProgramData\CA\JavelinConfig\x64\Extensions\GridTools.Javelin.HBaseActivities.dll"
  3. In Javelin, navigate to File → Options → Extensions (or click Import Extension).
  4. Select GridTools.Javelin.HBaseActivities.dll, assign Category HBase Activities, and click Import Selected.
