Overview & Architecture

The GridTools.Javelin.MongoDbActivities extension integrates MongoDB directly into CA Test Data Manager (TDM) Javelin workflows. Built natively on Windows Workflow Foundation (WF4) and inheriting from JavelinNativeActivity, it enables automation teams to query, seed, mask, aggregate, and teardown document-based datasets alongside standard relational databases (Oracle, SQL Server, DB2).

Core Capabilities Key Features
  • Native DataTable Interoperability: Automatically converts MongoDB BSON documents into standard ADO.NET DataTables for Javelin loops, CSV exports, and relational syncing.
  • TDM Password Decryption: Seamlessly resolves encrypted Javelin password tokens (%password_var%) in connection strings and JSON filters.
  • Direct BSON/JSON Support: Flexible single-quote relaxed JSON syntax (e.g., "{'status': 'ACTIVE'}").
Enterprise Security & Topology Connectivity
  • MongoDB Atlas Support: Full DNS Seedlist support via mongodb+srv:// URIs.
  • Authentication Schemes: Supports SCRAM-SHA-1, SCRAM-SHA-256, MONGODB-CR, and X.509 Certificates.
  • Connection Pooling: Concurrent client caching ensuring high throughput and minimal socket exhaustion during heavy workflow execution.

Installation & Setup
Important Dependency Layout
Javelin resolves assemblies directly from its Extensions folder. All companion DLLs must be placed flat inside the Extensions directory (not in subfolders).
  • Deploy DLLs to Javelin
    Copy the 12 compiled library files from the dist/ folder directly into:
    C:\Program Files (x86)\Grid-Tools\Javelin\Extensions\
    Required files: GridTools.Javelin.MongoDbActivities.dll, MongoDB.Driver.dll, MongoDB.Driver.Core.dll, MongoDB.Bson.dll, MongoDB.Libmongocrypt.dll, DnsClient.dll, SharpCompress.dll, Snappier.dll, ZstdSharp.dll, Microsoft.Bcl.AsyncInterfaces.dll, Microsoft.Extensions.Logging.Abstractions.dll, System.Buffers.dll.
  • Unblock Transferred Binaries (Windows Security Zone)
    Open PowerShell as Administrator on the Javelin machine and execute:
    Unblock-File "C:\Program Files (x86)\Grid-Tools\Javelin\Extensions\*.dll"
  • Import into Javelin Designer
    Open Javelin → File → Options → Extensions (or click Import Extension).
    Select GridTools.Javelin.MongoDbActivities.dll, verify the 6 detected activities, set the Category name to MongoDB Activities, and click Import Selected.

Connection Strings & Authentication Patterns
Deployment Scenario Connection String Format Notes
Local Standalone (No Auth) "mongodb://localhost:27017" Default local development / test harness.
Standard Auth (SCRAM) "mongodb://admin:%mongo_pass%@server01:27017/?authSource=admin" Uses Javelin's encrypted password variable %mongo_pass%.
Replica Set (High Availability) "mongodb://user:pass@node1:27017,node2:27017,node3:27017/?replicaSet=rs0&authSource=admin" Automatically routes reads/writes and handles primary failover.
MongoDB Atlas / Cloud (SRV) "mongodb+srv://tdm_user:%atlas_pwd%@cluster0.abcde.mongodb.net/?retryWrites=true&w=majority" Requires SSL (TLS 1.2+). Resolved seamlessly via embedded DnsClient.dll.
SSL / TLS Enabled "mongodb://user:pass@mongo-sec:27017/?ssl=true&sslVerifyCertificate=false&authSource=admin" Set sslVerifyCertificate=false if using internal self-signed CA certificates.

Activity Reference & Test Scenarios
1. MongoDB Find (MongoFindActivity) Query / Extraction

Queries documents from a collection with support for filtering, projection (column selection), sorting, and pagination. Outputs both a standard Javelin DataTable and a formatted JSON array.

Property Type / Direction Example Value Description
ConnectionString In / String "mongodb://localhost:27017" Target MongoDB instance URI.
DatabaseName In / String "sample_mflix" Target database name.
CollectionName In / String "movies" Collection to query.
FilterJson In / String "{'genres': 'Action', 'year': {'$gte': 2000}, 'imdb.rating': {'$gte': 8.0}}" BSON query filter. Use "{}" for all documents.
ProjectionJson In / String "{'_id': 0, 'title': 1, 'year': 1, 'imdb.rating': 1, 'runtime': 1}" Fields to include (1) or exclude (0). Excludes _id if set to 0.
SortJson In / String "{'imdb.rating': -1}" Sort criteria (-1 descending, 1 ascending).
Limit / Skip In / Int32 10 / 0 Maximum records to return and records to offset.
OutDataTable Out / DataTable Variable: dtMovies Populated ADO.NET DataTable ready for loops or CSV export.
OutJson Out / String Variable: jsonMovies Canonical Extended JSON array of matching documents.
OutCount Out / Int64 Variable: movieCount Total number of documents returned.
2. MongoDB Insert (MongoInsertActivity) Data Seeding

Inserts one or multiple documents into a MongoDB collection. Can accept a raw JSON string (single object or array) or an entire Javelin DataTable for bulk relational-to-document migration.

Property Type / Direction Example Value Description
ConnectionString In / String "mongodb://localhost:27017" MongoDB Connection URI.
DatabaseName / CollectionName In / String "testdb" / "tdm_customers" Destination database and collection.
DocumentJson In / String "[{'customerId': 101, 'name': 'Alice Smith', 'tier': 'Gold', 'balance': 1500.50}, {'customerId': 102, 'name': 'Bob Jones', 'tier': 'Silver', 'balance': 450.00}]" JSON object or array to insert.
InputDataTable In / DataTable dtSourceData (optional) If provided, converts all rows into documents and batch inserts them.
InsertedCount Out / Int32 Variable: insertedCount Number of documents inserted.
InsertedIdsJson Out / String Variable: idsJson JSON array containing the generated _id values.
3. MongoDB Update (MongoUpdateActivity) Data Masking / State Mutation

Updates documents matching a filter using standard MongoDB update operators ($set, $inc, $unset, $push). Supports IsUpdateMany and IsUpsert.

Property Type / Direction Example Value Description
FilterJson In / String "{'customerId': 102}" Filter identifying which document(s) to update.
UpdateJson In / String "{'$set': {'tier': 'Platinum', 'status': 'ACTIVE'}, '$inc': {'balance': 500}}" MongoDB update instructions.
IsUpdateMany In / Boolean False (or True) False updates the first matching document; True updates all matches.
IsUpsert In / Boolean False (or True) If True, creates a new document when no match is found.
MatchedCount / ModifiedCount Out / Int64 Variables: matched, modified Number of matched and actually changed records.
4. MongoDB Aggregate (MongoAggregateActivity) Analytics / Pipelines

Executes multi-stage aggregation pipelines for complex analytics, group summaries, lookups, and unwinding nested arrays.

Property Type / Direction Example Value Description
PipelineJson In / String "[{'$unwind': '$genres'}, {'$group': {'_id': '$genres', 'totalMovies': {'$sum': 1}, 'avgRating': {'$avg': '$imdb.rating'}}}, {'$sort': {'totalMovies': -1}}, {'$limit': 5}]" Array of pipeline stages ($match, $group, $sort, $lookup, etc.).
OutDataTable Out / DataTable Variable: dtAggResults Tabular aggregated result set.
OutJson Out / String Variable: jsonAggResults Aggregated results formatted in JSON.
5. MongoDB Delete (MongoDeleteActivity) Teardown

Removes documents matching filter criteria.

FilterJson: "{'customerId': {'$in': [101, 102, 103]}}"
IsDeleteMany: True
DeletedCount (Out): Variable: deletedCount
6. Execute Command (MongoExecuteCommandActivity) Admin

Runs administrative database commands.

DatabaseName: "admin" (or target DB)
CommandJson: "{'ping': 1}" or "{'drop': 'temp_coll'}"
IsOk (Out): True | ResponseJson: {"ok": 1.0}

Debugging & Printing Outputs in Javelin Workflows

Javelin expressions use VB.NET syntax. Below are convenient one-liners you can use in Log Message or WriteLine activities to inspect results during test execution:

Inspection Goal VB.NET Expression (for Javelin Log Message / WriteLine)
Print Full JSON Results jsonMovies (Uses the OutJson property directly)
Print DataTable as Delimited Text String.Join(Environment.NewLine, From row In dtMovies.Rows.Cast(Of System.Data.DataRow)() Select String.Join(" | ", row.ItemArray))
Print Row Count & Column Names "Rows: " & dtMovies.Rows.Count.ToString() & " | Columns: " & String.Join(", ", From col In dtMovies.Columns.Cast(Of System.Data.DataColumn)() Select col.ColumnName)
